# Contributing

This is a personal system, but the shape is reusable. To add or change anything, follow [docs/EXTENDING.md](docs/EXTENDING.md): scaffold with `kiwi new`, keep the frontmatter contract, run `node tests/run-all.js`, then `kiwi install`. Never include secrets or machine-specific paths in committed files. Commits are made by the owner; `kiwi` never commits.
